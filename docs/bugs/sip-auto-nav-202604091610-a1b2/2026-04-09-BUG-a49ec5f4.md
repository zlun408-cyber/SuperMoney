## 触发条件
- 前置条件: 用户在交易表单输入交易日期和基金代码
- 触发条件: 系统自动获取指定日期的净值

## 复现步骤（动作）
1. 打开交易表单（add-transaction-dialog.tsx）
2. 选择交易日期（如 2026-04-08）
3. 选择下单时段（如 before_1500）
4. 系统触发净值自动获取

## 期望结果
- 系统应获取 2026-04-08 的历史净值（已确认净值）
- 净值日期与交易日期一致（15点前）或次日（15点后）

## 实际结果
- 系统调用 fetchSingleFundQuote 返回实时估算净值（estimatedNav）
- 估算净值仅反映当前市场情况，不是历史净值
- 无法获取指定日期的历史净值数据

## 接口信息（涉及接口时必须填写）
- 接口名称/用途: 净值获取
- 请求方式: GET
- 路径: /api/funds/nav
- 参数（位置/字段/类型/值）:
  - fundCode (query, string, 必填): 基金代码
  - date (query, string, 必填): 日期 YYYY-MM-DD
- 请求示例:
  ```
  GET /api/funds/nav?fundCode=000001&date=2026-04-08
  ```
- 响应示例（成功/失败）:
  ```json
  {
    "success": true,
    "data": {
      "fundCode": "000001",
      "date": "2026-04-08",
      "nav": 1.2345,
      "source": "api",
      "updatedAt": "2026-04-09T16:00:00.000Z"
    }
  }
  ```
- 状态码/错误码: 200 / NAV_NOT_FOUND(404)

## 根因分析
- lib/funds/nav-cache.ts:65-81 fetchNavFromApi 调用 fetchSingleFundQuote
- fetchSingleFundQuote 返回 FundQuote.estimatedNav（实时估算净值）
- 天天基金 API (https://fundgz.1234567.com.cn/js/{code}.js) 只提供实时估算数据
- 缺少历史净值 API 对接

## 影响范围
- 所有交易表单的净值自动获取功能
- 定投执行时无法获取正确的 confirmedNav

## 临时解决方案
- 提示用户手动输入净值
- 在 UI 显示"无法获取历史净值，请手动输入"
