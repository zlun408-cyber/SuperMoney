## 缺口清单

### G1: 交易日历服务缺失
- **优先级**: P1
- **描述**: 无法判断某日是否为交易日（周末/节假日）
- **影响**: 净值获取可能返回非交易日数据
- **建议**: 引入交易日历 API 或硬编码中国 A 股交易日历（2026-2027）
- **关联 LedgerId**: L1 (Design)

### G2: 外部净值 API 对接未完成
- **优先级**: P1
- **描述**: 当前使用 MockFundDataSource，未对接实际数据源
- **影响**: 生产环境无法自动获取净值
- **建议**: BE 对接天天基金或蛋卷基金 API
- **关联 LedgerId**: L4 (Dev)

### G3: Supabase 净值缓存表未创建
- **优先级**: P2
- **描述**: L3 远程缓存需要数据库表支持
- **影响**: 净值缓存仅依赖内存和 localStorage，重启后丢失
- **建议**: 创建 `nav_cache` 表，存储历史净值缓存
- **关联 LedgerId**: L4 (Dev)

---

## 风险清单

### R1: API 频率限制
- **描述**: 外部 API 有请求频率限制
- **缓解**: 缓存策略 + 批量请求 + 用户手动输入兜底

### R2: 数据源不一致
- **描述**: 不同数据源净值可能有差异
- **缓解**: 固定单一数据源，记录 `source` 字段
