## 需求摘要
第四阶段目标：增强交易账本的可读性，提升用户理解持仓与收益的能力。

## 已完成功能清单
1. 详情页收益拆分卡片增强（总收益口径 / 分红说明）
2. 交易记录列表信息增强（净值 / 手续费 / 备注 / 类型标签）
3. 账本卡片分组展示（持仓概览 / 收益拆分）
4. 交易记录账本影响提示（买入后持仓 / 卖出后剩余份额 / 分红影响）
5. 交易记录排序切换（最新在前 / 最早在前）
6. 交易记录类型筛选（全部 / 买入 / 卖出 / 只看分红）
7. 交易记录按日期分组展示（账本时间线）
8. 日期分组笔数摘要与视觉强化
9. 同日多笔交易序号提示
10. 交易主数值高亮（金额 / 份额）
11. 交易次要信息条收紧
12. 工具栏状态摘要与辅助标签化
13. 筛选空状态提示与一键恢复
14. 交易模型基线重构（支持 placed/effective 日期结构）
15. 定投计划基线 UI（独立板块 / 新增弹层 / 列表展示）
16. 定投计划自动生成交易记录链路（source = sip_plan）
17. 定投计划云端持久化基线
18. 定投计划结束态 / 暂停态边界处理
